# Play recap

Open **Play recap** near **Goals** at the top of the **Kombo** dashboard. Use the standard selector's Kombo tab or the skinned selector's flame button. It is available even before creating a Kombo routine, and Back returns to the same dashboard.

Choose **Session**, **Daily**, **Weekly**, or **Custom**. Previous/Next selects older/newer periods; Latest returns to the current period. Sessions group local chart results less than 60 minutes apart, including across app restarts. The most recent session remains available after an idle gap. Days use local midnight; weeks start Monday. Custom dates use `YYYY-MM-DD` and include both dates.

The recap has separate **Lamp upgrades**, **Score upgrades**, and **BP upgrades** sections. A chart can appear in several sections. Each row compares the best before the period with the best achieved inside it; repeated upgrades are consolidated. **New** means no earlier eligible local record was found. Score is EX score; lower BP is better. BP follows beatoraja: BAD + POOR + empty-POOR/MISS + unpassed notes. Saved `bad_points` takes precedence, including its unpassed-note penalty on failed plays. Older rows without saved BP use BAD + POOR + KPOOR only when completion can be established. Invalid BP values are excluded. Lamp upgrades are grouped by the achieved lamp, best lamp first, with alphabetical chart order within each group in both the screen and receipt. Different LN modes remain separate, with legacy unknown-mode records retained as baselines according to the existing best-score policy.

Recaps cover local chart records, not courses or imported IR scores. They follow the existing score and lamp eligibility policies. Stored titles allow deleted charts to remain visible; old records without a resolved chart hash are excluded because they cannot be safely attributed to a chart. The available history determines the baseline.

Each chart shows its current difficulty-table labels, falling back to its chart level (`Lv.`) or `Lv. —` when metadata is unavailable. Library metadata supplies the title followed by its subtitle, matching the selector; removed charts retain the saved title. Compact rows put difficulty and LN mode in a narrow column alongside a small jacket, title, and record change; narrow screens stack the title and change. Jackets use the stage image, or the banner when no stage image is set, fitted without cropping. Missing or unreadable artwork uses the selector's music-note placeholder. Lamp groups use full-width headers in the app's standard lamp colors, and before/after lamps use small badges with dark text and a subtle border for pale lamps. Both the recap screen and exported image include these details.

**Export PNG** creates one receipt-style PNG containing all three sections, regardless of the currently visible list page. The paper-colored receipt is 960 pixels wide, with a compact header and table rows for difficulty, before/after values, and chart title. Its height grows with the content and long chart titles wrap. The profile and selected period appear at the top; counts sit in each section heading. The canvas is independent of device resolution and orientation. Long receipts render in bounded strips and stream into a single PNG, including receipts taller than the GPU texture limit.

Browsing loads jackets asynchronously. Export loads only the artwork in the strip being drawn and releases GPU textures after drawing, reusing the bounded thumbnail cache across repeated charts. It does not wait for asynchronous UI images or preload every jacket in the recap.

Desktop/Android files are saved under `Documents/recap_exports/<export-id>` in the app's document storage; iOS uses Photos. The screen reports the saved image path or an error. Incomplete PNG files are removed instead of exposing a truncated receipt. Keep the app in the foreground while it exports.

**Difficulty ranges** opens a Kombo-style table/from/to picker. Add inclusive ranges in the table’s displayed level order, then switch tables to add more; matching any selected level is sufficient. Overlapping ranges are deduplicated; consecutive selected levels are displayed and removed as ranges using the same table-order formatter as Kombo, and **All difficulties** clears the restriction. With no ranges selected, charts outside difficulty tables remain included. **Include new plays: On/Off** defaults to On; Off hides rows labeled New (no prior eligible record for that metric and LN mode). Filters remain selected while changing periods within this recap screen. Counts and the entire PNG use the same filtered results. The screen and PNG show the active filter summary, with consecutive difficulties grouped into ranges. This summary is omitted only from the share text.

On iOS and Android, **Share** opens the system share sheet with the same complete filtered PNG plus text containing the period, lamp/score/BP upgrade counts, and `#AsoBMaShow`. Sharing uses the private share cache and does not save a copy to Photos or request photo-library permission. The destination app decides how to use the image and text. Export PNG remains available for saving a file.
