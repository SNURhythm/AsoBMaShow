# Settings choice migration — 2026-10-24

## Changed to opposing-state cycles

- VSync.
- Club Beat.
- Lane covers SUDDEN+/HIDDEN+/LIFT (shared Settings, Play Options, lane preview).
- Efficient-video opt-in.
- Calibration mute/hide notes/hide feedback/logical judgement line.
- Scratchless table inclusion.
- Hide empty scratch lanes.
- Music-select toolbar Visible/Hidden.
- Skin HUD indicator and counter On/Off.

## Distinct two-mode choices

- Flick/Tap scratch input.
- LR2/Beatoraja ruleset.
- Visible-time unit Green Number/Milliseconds.
- Judgement indicator World/HUD layout.
- Keysound Input Trigger/Auto-Timed (Audio and Calibration).
- Input binding player1/player2.
- Virtual controller Flick/Spin scratch method.
- Virtual-controller player1/player2.
- Calibration meter 4/4 versus 3/4.

These use buttons if their labels fit, otherwise a dropdown. They do not cycle.

## Adaptive three/four-choice groups

- Note priority Lowest/Combo/Duration/Score.
- Counter Top/Left/Right.
- Gauge World/Left/Right.
- BGA Fit/Fill/Stretch.
- Screen Auto/Landscape/Portrait.
- Scratchless Disabled/Enabled/Selected Tables.
- Skin safety three levels.
- Side-tap Edge Lane/Scratch/Ignore.
- Long-note LN/CN/HCN.
- Assist Off/Drag/BPM Guide.
- Calibration four chart patterns.
- Window mode: Windowed / Borderless / Exclusive Fullscreen.

Shared skin HUD controls use the same policy. These groups become dropdowns when localized labels do not fit.

## Changed to dropdowns for larger sets

- Fixed Hi-Speed Off/Start/Max/Main/Min.
- FAST/SLOW and +/-ms thresholds PGreat/Great/Good/Bad/Off (HUD and built-in skin HUD).
- Six gauges.
- Five auto-shift modes.
- Six lower-bound gauges.
- Ten play-shuffle modes.
- Seven pacemakers.

Calibration spacing, input key mode, note type and keybomb judgement were already dropdowns and remain so.

## Dynamic lists

- Skin-defined configuration options with one or two entries now use dropdowns.
- Skin-defined file choices with one or two entries now use dropdowns.

Larger skin lists were already dropdowns. Language, devices, resolution, sample rates/buffers, AA and frame caps remain dropdowns. Unsupported playback time stretch remains visible but disabled in its existing dropdown.
