# Song selector fonts

- `roboto-condensed-regular.ttf` and `roboto-condensed-bold.ttf`: static 400/700
  instances of Google Fonts' Roboto Condensed variable font, generated with
  FontTools. Source: https://github.com/google/fonts/tree/main/ofl/robotocondensed
  License: `roboto-condensed-OFL.txt`. CJK text uses the existing Noto fallback.
- `fa-regular-400.ttf`: Font Awesome 6 regular icons, used for outline favorites.
  Source: https://github.com/FortAwesome/Font-Awesome/tree/6.x/webfonts
  License: `fontawesome-LICENSE.txt`.
